# Music

## Famous Beats Maker — Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Enter` | Play / Pause |
| `Arrow Up` | Previous beat preset |
| `Arrow Down` | Next beat preset |
| `Arrow Left` | Previous beat preset |
| `Arrow Right` | Next beat preset |
| `]` | Increase BPM by 2 |
| `[` | Decrease BPM by 2 |

Selecting a new preset (via dropdown or arrow keys) auto-starts playback.
